# Akeed Website

Responsive Akeed business travel landing page built with Next.js, React, and TypeScript.

## Live preview

https://sameer-ragab.github.io/akeed-website/

## Run locally

```bash
pnpm install
pnpm dev
```

Open http://localhost:3000 after the development server starts.

## Production build

```bash
pnpm build
```

The site is exported as static files in `out/`. Every push to `main` is deployed automatically to GitHub Pages.
